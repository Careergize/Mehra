# React + Tailwind CSS Starter

A lightweight React project powered by Vite and Tailwind CSS.

## Getting started

```sh
npm install
npm run dev
```

Open the local URL printed by Vite to view the app.

## Available scripts

- `npm run dev` — start the development server.
- `npm run build` — create a production build in `dist/`.
- `npm run preview` — serve the production build locally.

## Project structure

```text
.
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── App.jsx
    ├── index.css
    └── main.jsx
```

Add reusable UI in `src/components/`, route-level screens in `src/pages/`,
custom hooks in `src/hooks/`, and shared helpers in `src/lib/` as the project
grows.
